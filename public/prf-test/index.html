Can a passkey unlock your data key?

A test for FAIR2Adapt controlled-access data. Your passkey (fingerprint, face or device PIN) unlocks a private key kept in this browser; that key opens a dataset key wrapped for you, exactly as fair-data-access does. Nothing leaves this page. Run the four steps in order and send the report at the end.
